Trigger Economics

A trigger is a decision rule. Its quality is not R² — it is whether acting on it beats always act and never act.

Illustrative data

Somalia's anticipatory-action framework releases money when a flood forecast crosses a pre-agreed threshold. This page runs the cost–loss model that decides where that threshold should sit. Move the four parameters and watch the optimal release point, its contingency table, and its relative economic value V respond. The recurring surprise: the threshold that maximises forecast skill is usually not the one that releases money most wisely.

Parameters

C — what one activation costs, whether or not the flood comes.
L — damage from a flood nobody prepared for.
f — fraction of L avoided by acting early and correctly.
s — how often the flood happens, absent any forecast.
C / L = 0.033 feasible while C / L < f

Expected cost per season

Model units. The trigger is worth funding when its bar sits below both always act and never act.

How this is computed

For cost of action C, unmitigated loss L, mitigation effectiveness f and base rate s, each strategy has an expected expense per forecasting opportunity:

always act = C + (1−f)·s·L never act = s·L forecast = (hits + false_alarms)·C + hits·(1−f)·L + misses·L # hits, false_alarms, misses as rates perfect = s·(C + (1−f)·L) V = (E_reference − E_forecast) / (E_reference − E_perfect) E_reference = min(always act, never act)

The tool sweeps every threshold, builds the contingency table, and picks the one with the lowest expected expense — optionally subject to a POD floor or FAR ceiling. If C / L ≥ f the problem is infeasible: no threshold can beat the trivial strategies, and the fix is the intervention, not the trigger. If a limit cannot be met, the forecast is not skilful enough at that lead time — the tool says so rather than quietly relaxing it.

The forecast record is synthetic. 640 district–seasons from a seeded generator, base rate 0.091, discrimination AUC ≈ 0.91 — deliberately cleaner than SAAT's current displacement model (AUC ≈ 0.83) so the cost–loss geometry reads clearly. The maths mirrors saat.verification exactly. Nothing here is calibrated for Somalia; C, L, f and s are each a number someone has to defend to the working group.
