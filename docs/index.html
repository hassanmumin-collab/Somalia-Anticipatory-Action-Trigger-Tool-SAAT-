Somalia Anticipatory Action Trigger Tool

SAAT assesses Somalia's flood risk for a given El Niño/Indian Ocean Dipole forecast using a historical-analogue method: five documented Deyr-season floods since 1997, compared by ocean state and outcome, in place of scaling a single reference event by a strength ratio. This is the report that method produces for the 2026 Deyr.

Somalia's 2026 Deyr Flood Risk: A Historical-Analogue Assessment
A report by Hassan Mumin: five documented Deyr floods (1997–2023) compared by El Niño and Indian Ocean Dipole state, a Mogadishu drainage case study, two historically grounded ranges for 2026 depending on how the IOD resolves, and preparedness recommendations.
